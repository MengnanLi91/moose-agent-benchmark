# F4 — Input assembly and parameter wiring

## Capability

Assemble a syntactically and schematically valid input from an accepted MOOSE object plan.

## Isolation guidance

Supply the physics, weak form, and object map. Grade HIT structure, references, and parameter
wiring rather than formulation choices.

## Review questions

- Does the case distinguish syntax/schema failure from model-physics failure?
- Can private validation rerun the exact submitted artifact?
