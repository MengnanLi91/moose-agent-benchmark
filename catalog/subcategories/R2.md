# R2 — Residual, Jacobian, and coupling repair

## Capability

Repair an equation term, sign, Jacobian contribution, material dependency, or coupling.

Current R2 implementations must express the repair through MOOSE input configuration. They must not require participant C++ changes or application compilation.

## Isolation guidance

Supply the intended formulation and root-cause location. Exclude solver tuning from scoring.

## Review questions

- Is there one independent algebraic or coupling defect?
- Do tests detect unrelated changes to accepted model behavior?
