## Contributor workflow

1. Propose or select a case.
2. Copy the appropriate template and assign an owner.
3. Implement the catalog record and benchmark files.
4. Run catalog and benchmark validation.
5. Open a pull request for domain and benchmark-design review.

See the [catalog user guide](../docs/catalog-user-guide.md) for the complete workflow.
