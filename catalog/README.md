# Benchmark catalog

This directory is the human-facing development catalog for the MOOSE Agent Benchmark.
Benchmark contracts under `benchmark/` remain authoritative for execution and scoring.

## Start here

- Open [[Benchmark Dashboard]] in Obsidian.
- Copy a record from [[templates/atomic-case-record]] or
  [[templates/integrated-case-record]].
- Read the [catalog user guide](../docs/catalog-user-guide.md).
- Read the [catalog developer guide](../docs/catalog-developer-guide.md).
- Return to the [repository quick start](../README.md).

Obsidian edits these tracked Markdown files directly. Use Git to pull, commit, push, and
submit changes for review.
