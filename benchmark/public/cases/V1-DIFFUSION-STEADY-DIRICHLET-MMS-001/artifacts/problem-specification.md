# Problem specification

On the unit square $\Omega=[0,1]^2$, consider

$$
-\nabla^2 u=s.
$$

Use the manufactured field

$$
u^*(x,y)=\sin(\pi x)\sin(\pi y).
$$

Derive and report:

1. $\partial u^*/\partial x$, $\partial u^*/\partial y$, and $\nabla^2u^*$;
2. the source $s(x,y)$;
3. the Dirichlet value on each side of the square;
4. a short substitution showing that $u^*$ satisfies the manufactured problem.
