# Physics specification

Solve the three displacement components using quasi-static momentum balance and finite-strain
kinematics. Temperature is prescribed. Use isotropic linear elasticity with Young's modulus and
Poisson ratio. Fix all bottom displacements and leave the remaining surfaces traction free.
Report lateral centerline displacement at the core top, ACLP, and duct top.

No thermal eigenstrain or thermal-expansion closure is included.
